# 📊 Daily KPI Tool

業務システムから取得した日報をもとに、単日付帯率・単日注力KPIを自動計算するWebアプリです。

## 主な機能

* 業務システムの文章を貼り付けるだけで自動計算
* 単日付帯率を自動作成
* 単日注力KPIを自動作成
* ワンタップでクリップボードへコピー
* スマートフォン・PC両対応
* GitHub Pagesで公開

---

## 使用方法

① 業務システムの日報をコピー

② Daily KPI Toolへ貼り付け

③ 集計時刻を入力

④ 「計算」を押す

⑤ 「単日付帯率をコピー」

⑥ Teamsへ貼り付け

⑦ 「単日注力KPIをコピー」

⑧ Teamsへ貼り付け
