# 📊 Daily KPI Dashboard

毎日のKPI集計業務を効率化するために作成したWebアプリです。

業務システムから取得したデータを貼り付けるだけで、
付帯率・注力KPI・不足数を自動計算し、
報告用テキストをワンクリックで作成できます。

---

## ✨ 主な機能

- KPI自動計算
- 単日付帯率の自動出力
- 単日注力KPIの自動出力
- 出力内容をワンクリックでコピー
- KPI設定の保存（localStorage）
- KPI設定の読込
- 初期設定へ戻す
- GitHub Pages対応
- PC・スマートフォン対応

---

## 🖥️ 使用方法

1. KPI設定を確認
2. 業務システムのデータを入力欄へ貼り付け
3. 「計算」を押す
4. 出力①・出力②をコピー
5. 報告へ貼り付け

---

## 💾 保存機能

KPIの目標率はブラウザへ保存されます。

- ページを閉じても保持
- 次回起動時に自動読込
- 「初期設定へ戻す」でリセット可能

※保存先はブラウザの localStorage を使用しています。
